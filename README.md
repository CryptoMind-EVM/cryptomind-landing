# CryptoMind landing page

Static one-page site for [CryptoMind](https://getcryptomind.com): an AI market analyst and money ledger for crypto,
US and Taiwan stocks. English and Traditional Chinese, no build step.

- App: <https://getcryptomind.com>
- Source code: <https://github.com/CryptoMind-EVM/cryptomind>
- License: Apache-2.0

Open `index.html` in a browser, or run `python3 -m http.server`.
